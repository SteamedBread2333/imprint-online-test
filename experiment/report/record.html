1. 两类持久关联

规则 ↔ 文档（shelves）

  • sources：规则 → 文档；get r-… → resolved_sources。
  • find.links（当次）：sources / co_search；chunk get → referenced_rules。

规则 ↔ 规则（vault graph）

  • supersedes：新政策 → 旧政策（旧 dormant，find 默认不召回）。
  • conflicts_with：相反政策共存；find 返回 conflict_set，并对较弱一侧降权。
  • related：相关但不替代；get / desk /、/unified 看图。
  • referenced_by：谁指向我（get r-… 自动）。

2. 对照定义（规则↔文档）

对照无 vault 关联：用户消息 + grep 命中后 Read 规范文档全文（或宽 grep 全部命中篇）。
实验vault sources + shelves：一次 find(scope, query) 得 rules、documents、links；按场景仅 Read sources 指向的篇目或零 Read。
文档链持久 sources（规则→文档）；find.links kind=sources；get chunk → referenced_rules。
规则图持久 supersedes / related / conflicts_with（规则→规则）；find → conflict_set；get / desk /graph → referenced_by 等。
